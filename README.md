🚦 Smart Traffic Light System Using ESP32

📌 Project Overview

The Smart Traffic Light System is an IoT-based engineering project developed using the ESP32 microcontroller.

The system aims to improve road safety by detecting vehicles, monitoring traffic violations, and providing real-time alerts.

⚙️ Hardware Components

* ESP32 Development Board
* 2 × HC-SR04 Ultrasonic Sensors
* TFT Display (ILI9341)
* Buzzer
* Connecting Wires

💻 Software & Technologies

* Arduino IDE
* C/C++ Programming
* ESP32 Wi-Fi
* Telegram Bot API
* Web Server
* SPI Communication

🚀 Main Features

1. Smart Traffic Signal: Controls traffic light phases and timing.
2. Vehicle Detection: Uses ultrasonic sensors to detect approaching vehicles.
3. Red Light Violation Detection: Provides audible warnings and Telegram notifications.
4. Pedestrian Safety Monitoring: Detects potential hazards near pedestrian crossing areas.
5. TFT Dashboard: Displays traffic and system information.
6. IoT Connectivity: Uses Wi-Fi for remote monitoring and notifications.

🔌 System Architecture

The ESP32 acts as the main controller, receiving data from ultrasonic sensors and processing traffic conditions.

Based on the detected conditions, the system manages warning signals, updates the TFT display, and communicates alerts through Telegram.
